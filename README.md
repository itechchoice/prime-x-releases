# Prime-X internal releases

This private repository stores unsigned Prime-X desktop installers for internal testing.

Download installers and their matching checksum files from the [Releases](https://github.com/itechchoice/prime-x-releases/releases) page.

- Verify the matching `.sha256` file before installation.
- macOS builds use ad-hoc integrity signing and are not notarized.
- Windows builds are unsigned; an Unknown publisher or SmartScreen warning is expected.
- Share test account credentials through a separate approved channel, never through this repository.
